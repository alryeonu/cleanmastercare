# 청소 후 사진 검증 보상

## 무엇을 만들었는지

- 청소 안내의 단계 버튼과 전체 미션 완료 버튼에서 즉시 지급되던 포인트를 제거했다.
- 청소 전·후 사진이 같은 장소로 확인되고, 사진에서 보이는 완료 흔적이 있을 때만 `주변 정리`, `흔적 닦기`, `마무리 정리`에 각각 3포인트를 지급한다.
- 사진 없이 종료한 기록은 `사진 확인 대기`로 표시하며 포인트를 지급하지 않는다.
- 농장과 씨앗 잠금도 사진으로 확인된 단계가 하나 이상일 때 열리도록 연결했다.

## 문제·막힌 지점

기존 구현은 청소 단계를 화면에서 넘기기만 해도 포인트가 적립되어, 청소 후 사진에서 실제 완료 여부를 확인한 뒤 보상한다는 요구와 달랐다.

## 해결

청소 시나리오 진행 함수에서 모든 보상 호출을 제거했다. 전후 사진 분석 결과의 세 `mission_checks`만 보상 이벤트를 만들며, 같은 사진 조합은 기존 해시 중복 방지 로직으로 한 번만 처리한다.

## 다음 작업 시 참고

실제 API가 연결된 상태에서 전후 사진을 넣어 0·1·2·3개 단계가 각각 예상한 포인트만 적립하는지 확인한다. 예전 브라우저 localStorage에 남은 구형 단계 보상은 자동으로 제거하지 않는다.
