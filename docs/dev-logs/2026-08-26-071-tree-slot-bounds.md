# 기억의 나무 격자 경계 보정

## 무엇을 만들었는지

- 현재 나무의 외곽 크기를 격자 칸 기준으로 고정하고, 각 칸의 넘침을 숨겨 나무가 반드시 한 칸 안에 보이도록 보정했다.

## 문제·막힌 지점

- 아이소메트릭 나무의 원본 크기가 큰 상태에서 일부 성장 단계의 변형이 적용돼, 데스크톱 하단 칸에서도 나무가 크게 밖으로 나왔다.

## 해결

- 모든 성장 단계에 같은 격자용 외곽 스케일을 적용하고, 슬롯의 `overflow`를 숨김 처리했다.
- 운영 화면에서 위치 기준이 슬롯 하단으로 밀리는 것을 확인해, 현재 나무를 각 슬롯의 정확한 중앙에 절대 배치하도록 수정했다.
- 청소·Supabase·포인트·기록 데이터에는 변경이 없다.

## 다음 작업 시 참고

- 성장 단계별 실루엣을 크게 바꾸는 경우에는 1440px과 360px에서 슬롯 경계 검증을 먼저 실행한다.
