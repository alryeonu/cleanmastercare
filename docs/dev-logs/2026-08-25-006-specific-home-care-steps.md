# 장소별 구체 청소 순서

## 무엇을 만들었는지

- 책상, 싱크대, 소파, 침대·침구, 신발장, 욕실, 주방에 맞는 구체적인 정리·청소·세탁 단계를 추가했다.
- 예를 들어 싱크대 청소는 `거름망 비우기 → 주방세제와 부드러운 스펀지로 싱크볼 닦기 → 깨끗한 물로 헹구고 물기 닦기` 순서로 안내한다.
- 각 안내는 화면의 현재 분류를 표시해, 사용자가 어느 종류의 일을 하는지 알 수 있다.

## 문제·막힌 지점

공통 문구만 사용하면 싱크대·소파·침대처럼 준비물과 작업 순서가 다른 공간에서도 사용자가 다음 행동을 결정하기 어려웠다.

## 해결

장소와 작업 분류의 조합마다 작은 행동 단위의 계획을 만들었다. 재질·제품에 따라 달라지는 부분은 임의로 단정하지 않고, 작은 곳부터 시도하거나 제품·세탁 라벨을 따르도록 안내했다.

## 다음 작업 시 참고

사용자 사진과 각 장소 조합을 실제로 눌러 단계의 길이와 순서가 부담스럽지 않은지 확인한다. 곰팡이·혈액 등 특수 오염이나 전문적인 복원 작업은 별도 안전 흐름으로 분리해야 한다.
