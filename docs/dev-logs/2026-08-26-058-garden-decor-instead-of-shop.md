# 텃밭 자동 장식과 기록 화면 단순화

## 무엇을 만들었는지

- 기록 화면에서 농장 조경 구매, 농부 옷, 기프티콘 선택 패널을 제거했다.
- 완료된 돌봄 기록 수에 맞춰 텃밭에 꽃, 허수아비, 연못, 꽃밭이 자동으로 더해지게 했다.

## 문제·막힌 지점

- 기록 화면에 구매와 선택 영역이 많아 돌봄 기록을 확인하는 흐름이 분산됐다.

## 해결

- 기억의 조각 내역과 돌봄 기록만 남기고 텃밭 이동 경로를 유지했다.
- 장식은 별도 구매나 선택 없이 완료한 청소 미션의 성장 단계에 맞춰 텃밭 배경에 표시한다.
