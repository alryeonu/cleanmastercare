# 아이소메트릭 기억의 나무 스타일

## 무엇을 만들었는지

- 사용자가 제공한 참고 이미지의 구성감을 반영해 기억의 나무를 따뜻한 아이소메트릭 일러스트 스타일로 다듬었다.
- 중앙 나무에 다이아몬드형 흙 받침, 사선 그림자, 입체 줄기·가지, 면이 나뉜 잎 레이어를 추가했다.
- 기존 0·3·6·9·12·15포인트 누적 성장과 열매·완성 애니메이션은 유지했다.

## 문제·막힌 지점

- 이전 나무는 둥근 평면 잎의 비중이 커서 정원 전체의 2D 풍경과 비교해 깊이감이 약했다.

## 해결

- 외부 참고 이미지를 앱 자산으로 사용하지 않고, CSS `clip-path`와 그라데이션으로 등각 받침·나무 면·그림자를 그렸다.
- 성장 단계마다 같은 줄기와 잎 요소의 크기·가시성만 변하므로 나무가 다른 이미지로 교체되지 않는다.
- Supabase 데이터, 사진 분석, 청소 가이드, 기록과 제품 추천에는 변경이 없다.

## 다음 작업 시 참고

- 운영 배포 뒤 360px·768px·1440px에서 다이아몬드형 받침과 정보 바가 겹치지 않는지 다시 확인한다.
