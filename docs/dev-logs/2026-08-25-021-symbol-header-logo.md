# 심볼형 헤더 로고

## 무엇을 만들었는지

- 참고 이미지처럼 초록 얼굴 원형 심볼과 `청소의 고수` 글자를 나란히 배치한 헤더 로고로 변경했다.
- 헤더에서 쓰기 적합하도록 빗자루 없는 얼굴 전용 SVG 심볼을 만들었다.

## 문제·막힌 지점

- 기존 원본 캐릭터 이미지는 빗자루를 포함해 작은 헤더 마크에서 얼굴이 또렷하게 보이지 않았다.

## 해결

- 표정·볼·그라데이션을 포함한 가벼운 SVG 심볼을 만들고, 화면 폭에 맞춰 심볼과 글자 크기를 조절했다.
- CSS 캐시 버전을 올려 새 디자인이 즉시 로드되게 했다.

## 다음 작업 시 참고

- 앱 아이콘이나 파비콘이 필요해지면 같은 심볼에서 정사각형 아이콘 변형을 만든다.

## 검증

- JavaScript 문법 검사와 헤더·SVG 정적 파일 확인을 실행한다.
