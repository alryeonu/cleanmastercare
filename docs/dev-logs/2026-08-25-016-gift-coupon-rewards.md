# 기프티콘 보상 구성

## 무엇을 만들었는지

- 기프티콘 선택을 300P 편의점 3,000원 쿠폰, 500P 투썸 조각케이크, 1000P 올리브영 10,000원 쿠폰으로 변경했다.
- 올리브영 보상 카드에는 별도 SVG 로고 이미지를 적용했다.
- 프로토타입 기록·발송 제한 안내 문구를 제거했다.

## 문제·막힌 지점

- 이전 보상은 일반 간식 항목과 낮은 포인트로 되어 있어 사용자가 제공한 쿠폰 구성과 달랐다.

## 해결

- 포인트 금액, 제목, 설명, 버튼의 표기를 함께 교체했다.
- 외부 이미지 링크 대신 프로젝트 안의 가벼운 로고 SVG를 사용해 화면 로딩에 의존성이 없게 했다.
- 정적 파일 캐시 버전을 갱신해 이미 열린 화면에도 변경이 반영된다.

## 다음 작업 시 참고

- 실제 쿠폰 발송 기능을 추가하려면 제휴·결제·재고·발송 상태와 법적 고지를 별도 설계해야 한다.

## 검증

- JavaScript 문법 검사와 기프티콘 렌더링 정적 확인을 실행한다.
