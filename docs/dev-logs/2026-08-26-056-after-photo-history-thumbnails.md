# 애프터 사진 기록 썸네일

## 무엇을 만들었는지

- 일반 모드의 전후 사진 비교가 완료되면 애프터 사진을 긴 변 280px, JPEG 품질 0.62의 작은 썸네일로 만들어 사용자별 브라우저 `localStorage` 기록에 저장한다.
- 돌봄 기록 카드에 완료 날짜, 청소 항목, 모드, 격려 문구와 애프터 사진 썸네일을 함께 표시한다.
- 홈 화면의 `사진 원본 비저장` 문구를 `나만의 돌봄 기록`으로 교체하고 정적 파일 캐시를 `weekly-guide9`로 갱신했다.

## 문제·막힌 지점

- 사용자는 청소 후 변화를 개인 기록처럼 다시 보고 싶었지만, 기존 기록에는 사진 데이터가 없어 카드에 표시할 수 없었다.

## 해결

- 사용자 명시 승인에 따라 원본 전체가 아닌 축소된 애프터 JPEG 썸네일만 로그인별 브라우저 저장소에 보관한다.
- 썸네일은 서버, 로그, Supabase 테이블로 전송하거나 저장하지 않는다.
