# 원형 캐릭터 로고

## 무엇을 만들었는지

- 상단 브랜드 마크를 원형 배지로 바꾸고, 대표 스위퍼 캐릭터가 원 안을 가득 채우도록 조정했다.

## 문제·막힌 지점

- 이전 마크에는 정사각형·기울기 스타일이 남아 있어 캐릭터 로고가 둥근 심볼처럼 보이지 않았다.

## 해결

- 원형 마스크와 민트 그라데이션 배경을 적용하고, 이미지를 확대·중앙 정렬했다.
- CSS 버전을 갱신해 이미 열려 있는 브라우저에서도 새 로고가 로드되게 했다.

## 다음 작업 시 참고

- 로고 원본의 투명 여백이 더 커질 경우 이미지 크기와 세로 이동값만 미세 조정한다.

## 검증

- `node --check static/app.js`를 실행한다.
