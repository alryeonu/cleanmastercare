# 유연한 완료 판정과 STEP 주의 카드

## 무엇을 만들었는지

- 전후 사진에서 선택한 작업 중 한 가지 이상이 확인되면 장소 미션을 완료로 인정하고 새 장소 시작 버튼을 열도록 완화했다.
- 모든 청소 STEP에 `멈추고 확인할 것` 카드를 추가했다.
- 정리·청소·세탁별로 무거운 물건, 표면 손상·강한 냄새, 전기 제품, 세탁 라벨 같은 주의 지점을 표시한다.

## 문제·막힌 지점

- 모든 선택 항목이 사진에서 확인되어야만 완료되는 조건은 사진 구도나 AI 관찰의 한계 때문에 사용자에게 지나치게 엄격했다.
- 구체적인 방법을 안내하면서도 위험하거나 손상 가능성이 있는 상황을 놓치지 않아야 했다.

## 해결

- 완료 기준을 `사진에서 하나 이상의 선택 미션이 확인됨`으로 변경했다. 완료는 행동을 격려하는 진행 상태이며 청결도 평가가 아니다.
- STEP별 경고는 세제 혼합·희석비율을 제안하지 않고, 중단·확인·전원 차단·라벨 확인처럼 즉시 실행할 수 있는 안전 행동만 담았다.

## 다음 작업 시 참고

- 사진 비교 AI가 불확실할 때도 사용자가 스스로 기록만 남기는 흐름은 유지한다.
- 새 오염 유형을 추가하면 해당 유형의 `멈추고 확인할 것` 문구도 함께 작성한다.
