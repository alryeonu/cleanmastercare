# 기억의 나무 누적 성장 그래픽

## 무엇을 만들었는지

- 사용자에게 보이는 `텃밭` 관련 이름을 `기억의 나무`로 정리했다.
- 중앙 나무를 흙·줄기·가지·잎·꽃·열매의 누적 CSS 요소로 구성해, 포인트에 따라 자연스럽게 자라도록 바꿨다.
- 0·3·6·9·12·15포인트에 맞춰 빈 흙, 새싹, 가지, 잎, 작은 열매 두 개, 완성 열매 세 개가 순서대로 보이게 했다.
- 15포인트 달성 때 완성 나무를 짧게 유지하며 열매·은은한 빛·반짝임을 보인 뒤, 과수원 보관 및 다음 나무 시작 흐름을 유지했다.

## 문제·막힌 지점

- 이전 그래픽은 단계별로 고정된 나무 덩어리를 바꾸는 방식이라, 앞 단계가 자라 이어지는 느낌이 약했다.
- 기존 화면 문구에 `텃밭`, `기억나무`처럼 새 명칭과 일치하지 않는 표현이 남아 있었다.

## 직접 원인과 근본 원인

- 성장 상태는 있었지만 줄기·가지·잎·열매를 분리해 점진적으로 표현하는 DOM/CSS 계약이 없었다.
- 완료 시 바로 다음 나무로 초기화돼 완성된 열매를 중앙에서 보는 시간이 충분하지 않았다.

## 해결

- `activeTreeStage()`를 `seed → sprout → branching → leafy → fruiting → ripe`로 명확히 분리했다.
- `ripeTreePreview` 상태로 완성 나무를 약 2.8초 표시한 뒤 과수원 기록 패널을 연다.
- 열매는 12점에 두 개, 15점에 세 개가 보이며 완성 시 순차적으로 작게 튀어나오는 애니메이션을 적용했다. `prefers-reduced-motion`에서는 해당 애니메이션을 끈다.
- Supabase 청소 절차 조회, 사진 분석, NORMAL 제품 추천, 완료 사진의 브라우저 저장은 변경하지 않았고 DB 스키마·데이터도 변경하지 않았다.

## 남은 위험과 제한

- 완성 나무와 기록은 기존처럼 사용자의 브라우저 저장소에 보관되므로 다른 기기에 자동 동기화되지 않는다.
- 과수원 나무는 개별 기록 패널을 통해 볼 수 있으며, 실제 혜택은 쿠팡 검색 링크만 제공한다.
