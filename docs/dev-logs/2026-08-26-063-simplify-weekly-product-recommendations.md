# 주간 제품 추천 화면 단순화

## 무엇을 만들었는지

- 진행 중인 돌봄 계획에서 청소 모드 선택을 오늘 카드 한 곳으로 줄였다.
- `확인한 표면 재질` 선택을 제거했다.
- NORMAL 제품 추천을 청소 안내 바로 아래의 큰 세로 카드 두 개로 정리하고, 쿠팡 스타일의 제품명·목적·주의·보기 버튼을 유지했다.

## 문제·막힌 지점

- 같은 모드 선택이 주간 계획 상단과 오늘 카드에 동시에 있어 화면이 복잡해졌다.
- 재질 선택은 제품 추천을 보기 위한 추가 단계가 되어 주간 돌봄의 가벼운 흐름과 맞지 않았다.

## 해결

- 초기 계획 설정 단계의 선택은 유지하되, 이미 계획이 있는 화면에서는 오늘 카드의 선택만 보이게 했다.
- 추천 기준을 사진 관찰 후보의 공간·오염 종류로 단순화했다.
- 카드 레이아웃을 한 줄씩 크게 보여 주고, NORMAL일 때 사진 확인 전에도 카드가 청소 안내 아래에 나타날 것을 알린다.

## 테스트

- `node --check static/app.js` — 성공.
- `py -B -m pytest -q -p no:cacheprovider` — 성공.
- `git diff --check` — 성공.

## 다음 작업 시 참고

- 제품 추천은 NORMAL의 보조 정보만 유지한다. 제품 추천을 별도 화면이나 장바구니 흐름으로 확장하지 않는다.
