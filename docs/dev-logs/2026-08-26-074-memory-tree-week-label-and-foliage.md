# 기억의 나무 주차 표기와 기본 잎 보강

## 무엇을 만들었는지

- 기억의 나무 정보 바의 일반적인 `이번 주` 문구를 월·주차가 보이는 이름으로 바꿨다.
- 주간 시작일은 월요일로 계산하며, 예를 들어 8월 24일이 시작인 주는 `8월의 넷째 주 나무`로 표시한다.
- 기본 성장 상태인 나무에도 잎 일곱 장을 표시해, 첫 청소 전에도 나무가 충분히 풍성해 보이도록 했다.

## 문제·막힌 지점

- `이번 주`는 기록이 어느 시기의 나무인지 알려주지 않아, 시간이 지나면 과수원 기록을 구별하기 어려웠다.
- 기본 나무는 두 장의 잎만 보여 빈 나무처럼 느껴졌다.

## 해결

- 주간 키를 바탕으로 월의 첫 월요일부터 주차를 계산하는 `careWeekTitle()` 함수를 추가하고, 화면 안내와 접근성 이름에 함께 적용했다.
- 기존 나무·열매 성장 구조는 바꾸지 않고 `branching` 기본 상태에서 모든 잎 요소를 보이게 했다.
