# 청소 후 사진 최종 등록

## 무엇을 만들었는지

- 미션 시작 화면에서는 청소 전 사진만 등록하도록 바꿨다.
- 안내된 모든 단계를 마친 뒤에만 보이는 완료 확인 화면에 청소 후 사진 등록 영역을 옮겼다.
- 등록한 청소 후 사진은 즉시 미리보기와 전후 비교 카드에 함께 표시된다.

## 문제·막힌 지점

청소 후 사진 입력이 미션 시작 화면에 함께 있으면 사용자가 실제 청소를 끝내기 전에 AFTER 사진을 넣을 수 있어, 완료 검증 흐름이 어색했다.

## 해결

`afterImage` 입력을 완료 섹션으로 이동했다. 기존 비교·해시·포인트 로직은 같은 입력 ID를 사용하므로, 청소 후 사진 선택 시에만 비교를 실행하도록 그대로 유지된다.

## 다음 작업 시 참고

사진 등록 전에는 비교 버튼을 누르면 안내 메시지가 나오는지, 사진 등록 뒤 전후 미리보기와 완료 체크리스트가 모두 갱신되는지 실제 브라우저에서 확인한다.

## 검증

- HTML에서 청소 후 사진 입력 ID가 하나만 존재하는지 확인
- JavaScript 문법 검사
- 로컬 정적 페이지 응답 확인
