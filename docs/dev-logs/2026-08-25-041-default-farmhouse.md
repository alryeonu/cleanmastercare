# 기본 농가 유지

## 무엇을 만들었는지

- 돌봄 농장의 농가를 포인트·사진·미션 기록과 무관하게 처음부터 항상 표시하도록 변경했다.
- 기록이 없는 계정에도 농부 친구와 농가가 먼저 보이고, 햇살·밭·작물·창고·과수원만 행동에 따라 이어서 열린다.

## 문제·막힌 지점

- 닉네임별 저장 공간으로 분리한 뒤 새 프로필에서 과거 행동 이벤트가 없으면 농가도 잠긴 상태로 처리됐다.
- 잠긴 농장 아이템을 완전히 숨기도록 한 이전 시각 개선과 겹쳐 농가가 사라진 것처럼 보였다.

## 해결

- 농가의 해금 조건을 항상 참으로 두고 기본 농장 구성으로 처리했다.
- 기본 농가 1개가 표시될 때 맞는 안내 문구로 바꿨다.
- 브라우저가 이전 농장 로직을 재사용하지 않도록 `app.js` 캐시 버전을 갱신했다.
- 포인트, 기록, DB, 사진 원본 저장 정책은 변경하지 않았다.
