# OpenAI 연결 설정

## 무엇을 만들었는지

- 기존 프로젝트의 `.env`에서 OpenAI API 키 설정을 새 프로젝트로 복사했다.
- 새 설정을 읽는 로컬 서버를 포트 8003에서 실행했다.

## 문제·막힌 지점

새 프로젝트에 `.env`가 없어 사진 분석이 수동 모드로만 동작했다. 이미 실행 중인 서버는 새 환경 변수를 자동으로 읽지 않는다.

## 해결

사용자 승인 후 키 값을 노출하지 않고 기존 `.env`를 복사하고, 새 서버 프로세스를 시작했다.

## 다음 작업 시 참고

API 키는 채팅·로그·화면에 표시하지 않는다. 환경 설정을 바꾼 뒤에는 새 서버 프로세스를 실행해 `/health`로 연결 상태만 확인한다.

## 검증

- `http://127.0.0.1:8003/health`에서 `openai_configured: true`와 `gpt-5.6-luna` 확인
