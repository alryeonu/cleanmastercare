# 집안 돌봄 분류와 Google 검색

## 무엇을 만들었는지

- 장소를 책상, 싱크대, 소파, 침대·침구, 신발장, 욕실, 주방, 다른 공간에서 고를 수 있게 했다.
- `정리할 것`, `청소할 것`, `세탁할 것`을 복수 선택하고, 선택한 분류별 청소 단계를 순서대로 나열한다.
- 선택한 장소·분류를 Google 검색어로 만들어 사용자가 버튼을 눌러 더 많은 방법을 찾아볼 수 있게 했다.
- AI 사진 관찰과 전후 사진 비교에 선택한 장소·분류를 전달한다. 비교에서는 선택한 분류에 한해서만 개선 여부를 재검토하고 포인트를 지급한다.

## 문제·막힌 지점

기존 PRD와 프롬프트는 욕실 오염 후보에 한정되어 있어 책상·소파·침구·신발장처럼 일반적인 집안 공간을 설명하거나, 정리와 세탁을 구분할 수 없었다.

## 해결

분석 스키마를 집안 공간과 세 가지 작업 분류로 넓히고, 클라이언트 선택값을 분석 요청의 제한된 문맥으로 전달했다. 세제 사용량·재질 적합성·청결 점수는 여전히 생성하지 않는다. Google 검색은 서버에 검색 결과를 저장하지 않는 사용자 주도 새 탭 링크 방식으로 구현했다.

## 다음 작업 시 참고

실제 키를 연결해 장소별 사진으로 `visible_categories`와 전후 `mission_checks`가 선택하지 않은 분류를 false로 반환하는지 확인한다. Google 검색 결과의 신뢰성은 앱이 보증하지 않으므로, 향후 공식 안전 자료만 별도 큐레이션하려면 출처 검토 기능이 필요하다.

## 검증

- JavaScript 문법 검사
- 서버 스키마 및 고정 모델 확인
- 기존 Python 회귀 테스트
- Google 검색 버튼이 `q` 쿼리 파라미터를 URL 인코딩해 생성하는 정적 검사
- 새 백엔드가 반영된 포트 8002의 `/health`와 `care-scope.css` 응답 확인
