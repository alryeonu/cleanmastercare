# 완료 장소 잠금과 새 미션 시작

## 무엇을 만들었는지

- 전후 사진 비교에서 선택한 모든 작업 유형이 확인되면 `새로운 장소 청소 시작하기` 버튼을 표시한다.
- 새 미션을 시작하면 사진·단계·전후 비교 화면을 초기화하고 장소 선택 화면으로 돌아간다.
- 사진으로 완료된 장소는 브라우저 기록에 저장해 이후 장소 선택 목록에서 `완료`로 표시하고 선택할 수 없게 했다.

## 문제·막힌 지점

- 마지막 STEP까지 본 것만으로는 실제 청소 완료 여부를 알 수 없으므로, 장소를 즉시 잠그면 재시도를 막을 수 있었다.
- 한 장소에서 정리·청소·세탁을 함께 선택한 경우 일부만 전후 사진에서 확인될 수 있다.

## 해결

- 전후 사진에서 사용자가 선택한 모든 작업 유형이 확인된 경우에만 장소를 완료 처리했다.
- 일부만 확인되거나 AI 비교가 불가능한 경우에는 장소를 잠그지 않아 다시 시도할 수 있다.
- 완료 장소 목록은 사진 원본 없이 장소 코드만 브라우저 localStorage에 저장한다.

## 다음 작업 시 참고

- 현재 잠금은 이 프로토타입 브라우저에서 유지된다. 사용자가 원하면 완료 장소를 다시 열 수 있는 별도 관리 기능을 추가한다.
- 장소 잠금은 청결도 평가가 아니라, 이미 인증한 미션을 중복 실행하지 않도록 돕는 진행 상태다.
