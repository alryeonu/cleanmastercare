# 청소 미션당 한 칸 새싹

## 무엇을 만들었는지

- 밭 안에 표시하던 `새싹` 제목과 다음 단계 설명을 완전히 제거했다.
- 완료된 청소 미션 하나는 빈 밭 한 칸에 무작위 작물 새싹 하나만 심도록 변경했다.
- 장식용으로 여러 칸에 미리 표시되던 잎·새싹 이모지를 제거하고, 네 칸의 빈 밭은 실제 완료 기록 수만큼만 채워진다.

## 문제·막힌 지점

- 이전 구성은 성장 안내 문구가 밭 중앙에 표시되고, 장식용 식물이 여러 칸에 있어 한 번의 완료보다 많은 새싹이 심긴 것처럼 보였다.

## 해결

- 완료 기록 수에 맞춰 `gardenPlants` 브라우저 상태를 동기화하고, 각 밭 칸을 식물이 있을 때만 렌더링하게 했다.
- 사진 원본이나 사용자 기록을 Supabase에 추가 저장하지 않았으며, 기존 Supabase 청소 안내 연결도 변경하지 않았다.

## 테스트

- `node --check static/app.js`
- `py -B -m pytest -q -p no:cacheprovider`
- `git diff --check`

## 다음 작업 시 참고

- 텃밭의 빈 칸은 장식용 새싹으로 채우지 않는다.
- 완료 1회는 새싹 1개라는 대응을 유지한다.
