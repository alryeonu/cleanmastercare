# 단순 텃밭과 한 화면 청소 안내

## 무엇을 만들었는지

- 돌봄 농장의 해금 목록, 네 나무 선택, 물 주기, 수확, 타이머와 농부 설정을 텃밭 화면에서 제거했다.
- 청소 미션 완료 기록에 따라 `텃밭 → 기억의 조각 씨앗 → 새싹 → 작은 나무 → 큰 나무 → 과수원`으로 자동 성장하는 단일 텃밭을 만들었다.
- 청소 미션의 장소 선택에서 정리·청소·세탁 체크 설정을 제거하고, 장소와 청소 전 사진만 먼저 받도록 단순화했다.
- 사용자 확인 뒤의 검수된 6단계 청소 안내를 한 화면의 카드 목록으로 모두 표시하도록 변경했다.
- 각 안내 카드에 기존 브라우저 음성 안내를 유지하고, 단계마다 `완료`를 눌러 넘기던 동작을 제거했다.

## 문제·막힌 지점

- 기존 농장에는 행동 보상과 무관한 선택·물 주기·타이머·수확 조작이 반복되어 텃밭 성장의 의미가 복잡해졌다.
- 기존 청소 안내는 6단계마다 완료 버튼을 눌러야 사진 비교 단계로 갈 수 있었다.
- 운영 주소는 첫 확인에서 이전 정적 HTML을 브라우저 캐시로 표시했다.

## 직접 원인과 근본 원인

- 직접 원인은 농장 성장 상태가 미션 완료 기록과 별도 수동 농장 상태로 나뉘어 있던 점이다.
- 근본 원인은 사용자가 원하는 작은 행동 중심의 흐름보다 기능 조작이 앞선 설계였다.

## 해결

- 전후 사진 비교로 완료된 청소 미션 수만 계산해 여섯 텃밭 단계 중 현재 단계를 렌더링한다.
- 모든 6단계 안내를 한 번에 렌더링하고 단계별 음성 버튼만 남겼다.
- 사진 관찰 → 사용자 확인 → 청소 실행의 필수 안전 흐름과 AI 실패 시 직접 선택 경로는 유지했다.
- 운영 확인 시 캐시 식별자가 바뀐 주소로 다시 열어 새 정적 파일 반영을 검증했다.

## 실행한 테스트와 실제 결과

- `node --check static/app.js`: 성공.
- `py -B -m pytest -q -p no:cacheprovider`: 39 passed.
- `git diff --check`: 성공.
- Production 텃밭 확인: 해금 목록·나무 선택·물 주기·수확 UI 없음, 현재 저장된 1회 기록이 `기억의 조각 씨앗` 단계로 표시됨.
- Production 청소 미션 시작 확인: 표시 입력은 장소와 청소 전 사진뿐이며, 기존 단계별 완료 버튼이 없음.
- Production 360px 확인: 문서 폭 345px, 화면 폭 360px로 텃밭과 청소 미션에 가로 넘침 없음.
- Vercel Production 배포 완료: `https://clean-master-care.vercel.app`

## 남은 위험과 제한

- 기존 수동 농장 저장 데이터는 보존되지만 텃밭 화면의 진행도는 완료된 전후 사진 미션 기록만 사용한다.
- 청소 전후 사진 비교가 완료되지 않은 진행 중 기록은 텃밭 단계에 포함되지 않는다.

## 다음 작업과 다음 세션의 첫 행동

- 다음 작업은 사용자의 후속 요청을 기준으로 정한다.
- 텃밭 또는 미션 흐름을 바꿀 때는 사진 관찰·사용자 확인·6단계 안내·전후 확인 대체 경로가 유지되는지 먼저 확인한다.

## 다음 세션이 확인할 파일과 회귀 주의사항

- 확인 파일: `static/index.html`, `static/app.js`, `static/styles.css`, `test_rules.py`, `PRD.md`.
- 텃밭에는 별도 씨앗 구매, 나무 선택, 물 주기, 수확, 성장 타이머 UI를 다시 추가하지 않는다.
- 6단계 안내는 한 화면에 유지하고, 사진 원본을 브라우저 저장소나 서버에 보관하지 않는다.
