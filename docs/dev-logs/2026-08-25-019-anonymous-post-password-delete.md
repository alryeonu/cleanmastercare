# 익명 글 비밀번호 삭제

## 무엇을 만들었는지

- 익명 게시글 작성 시 삭제용 비밀번호를 설정하도록 추가했다.
- 작성한 글의 `내 글 삭제` 영역에서 같은 비밀번호를 다시 입력하면 글을 삭제할 수 있게 했다.

## 문제·막힌 지점

- 익명 게시판에는 계정이나 작성자 식별 정보가 없어 본인 글만 삭제할 방법이 없었다.

## 해결

- 비밀번호 원문은 저장하지 않고, 무작위 솔트와 scrypt 해시만 서버 메모리에 보관한다.
- 게시글 목록 API에는 해시·솔트를 제외해 클라이언트에 노출하지 않는다.

## 다음 작업 시 참고

- 실제 서비스에서는 삭제 시도 횟수 제한, 신고·관리자 삭제, 지속형 저장소와 보존 정책을 추가한다.

## 검증

- `node --check static/app.js` 통과.
- 실제 API에서 글 생성, 잘못된 비밀번호의 400 거절, 올바른 비밀번호의 삭제를 확인했다.
