# 싱크대 주간 사진 인식 보정

## 무엇을 만들었는지

- 주간 계획의 `싱크대` 사진이 AI에서 `주방`으로 넓게 분류돼도 싱크대 계획의 사진으로 인정하도록 공간 계층 보정을 추가했다.
- 사진 분석 프롬프트에 싱크볼·배수구·수전·설거지 그릇·싱크대 상판이 중심일 때 `sink`를 우선 반환하도록 명시했다.

## 문제·막힌 지점

- 싱크대 사진을 올렸는데 화면이 사진 재등록을 요구했다.

## 직접 원인과 근본 원인

- 주간 계획은 `analysis.area_hint !== task.area`의 완전 일치 비교만 사용했다. 따라서 싱크대를 포함한 주방 사진이 `kitchen`으로 분류될 경우 올바른 사진도 거절됐다.

## 해결

- `weeklyAreaMatches()`에서 `sink`와 `kitchen`을 서로 인접한 주간 계획 공간으로 처리했다.
- 이 보정은 싱크대·주방 사이에만 적용하며 욕실·침실 등 다른 공간 사진은 계속 재등록을 요구한다.

## 테스트

- `node --check static/app.js` — 성공.
- `py -B -c "compile(open('server.py', encoding='utf-8').read(), 'server.py', 'exec')"` — 성공.
- `py -B -m pytest -q -p no:cacheprovider` — 성공.
- `git diff --check` — 성공.

## 다음 작업 시 참고

- 주간 계획의 세부 공간 계층을 늘릴 때는 사진이 실제로 다른 장소로 잘못 통과하지 않도록 관계별로 제한된 별칭만 추가한다.
