# 싱크대 거름망 구체 안내

## 무엇을 만들었는지

- 싱크대 청소의 거름망 단계를 준비물과 실제 작업 순서로 구체화했다.
- `꺼내기 → 찌꺼기 버리기 → 따뜻한 비눗물에 불리기 → 전용 작은 브러시로 안팎 닦기 → 헹군 뒤 건조` 흐름을 안내한다.

## 문제·막힌 지점

기존의 ‘거름망을 비우기’ 문구만으로는 어떤 도구를 쓰고 어느 방향으로 닦아야 하는지 알기 어려웠다.

## 해결

고무장갑, 쓰레기봉투, 작은 볼, 주방세제, 전용 작은 브러시를 명시했다. 날카로운 도구나 거친 금속 수세미는 망을 손상시킬 수 있어 피하도록 안내했다.

## 다음 작업 시 참고

다른 장소의 핵심 단계에도 준비물과 행동 순서를 같은 형식으로 추가한다. 세제 양·희석비율·방치시간은 제품과 재질에 따라 달라 임의로 넣지 않는다.

## 검증

- JavaScript 문법 검사
- 싱크대 거름망 단계의 준비물·안전 문구 정적 검사
- 앱 JavaScript URL 버전을 갱신해 최신 안내가 로드되도록 처리
