# 주간 모드와 제품 추천 상태 상시 표시

## 무엇을 만들었는지

- `EASY`와 `NORMAL` 선택을 주간 계획 상단뿐 아니라 오늘의 돌봄 카드 안에도 항상 표시했다.
- NORMAL에서 사진 인식 전 또는 재등록 안내 중에도 `AI 제품 추천`이 사진 확인 뒤 표시될 위치와 조건을 안내한다.
- AI가 사진 장소를 보수적으로 거절했을 때 사용자가 계획 장소를 직접 확인하고 계속할 수 있는 버튼을 추가했다.

## 문제·막힌 지점

- 모드 선택이 주간 캘린더 상단에만 있어 오늘 카드만 보고 진행할 때 선택지가 사라진 것처럼 보였다.
- 제품 추천은 사진 인식 성공 뒤에만 표시돼, 사진이 거절된 상태에서는 기능 자체가 없는 것처럼 보였다.

## 해결

- 카드 내부 모드 선택은 현재 모드를 즉시 저장하고 같은 사진 분석·청소 안내 결과를 EASY/NORMAL 방식으로 다시 렌더링한다.
- 직접 확인 버튼은 AI를 정답으로 바꾸지 않는다. 사용자가 사진이 계획 장소임을 명시적으로 확인한 경우에만 해당 장소의 Supabase 청소 안내를 이어서 열며, NORMAL이면 정적 제품 참고 카드도 표시한다.

## 테스트

- `node --check static/app.js` — 성공.
- `py -B -m pytest -q -p no:cacheprovider` — 성공.
- `git diff --check` — 성공.

## 다음 작업 시 참고

- 직접 확인은 사진이 실제 계획 장소일 때만 사용하도록 문구를 유지한다. 무관한 사진을 자동으로 통과시키는 규칙으로 확장하지 않는다.
