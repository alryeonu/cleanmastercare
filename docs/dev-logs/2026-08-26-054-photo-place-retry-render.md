# 사진 장소 재등록 안내 렌더링 수정

## 무엇을 만들었는지

- 주간 계획 사진의 장소 확인이 불일치·불확실·시간 초과일 때, 해당 계획 장소의 재등록 안내가 실제 화면에 표시되도록 수정했다.

## 문제·막힌 지점

- 운영 API는 Supabase의 싱크대 청소 절차 6단계를 정상 반환했지만, 사진 장소 확인 실패 상태에 `area`가 없었다.
- 렌더러는 현재 계획의 `area`와 일치하는 안내만 표시하므로, 실패 후에는 계속 확인 중인 것처럼 보이고 단계나 재등록 안내가 나타나지 않았다.

## 해결

- 모든 사진 장소 확인 실패 상태에 `area: task.area`를 보존했다.
- 이제 사진이 계획 장소와 일치하면 Supabase의 6단계 안내가 표시되고, 일치하지 않거나 제한 시간을 넘기면 해당 장소 사진을 다시 등록하도록 명확히 표시된다.

## 테스트

- 운영 `POST /api/cleaning-guide` 싱크대 요청 — `mode: canonical`, `knowledge_source: supabase_release`, 6단계 반환 확인.
- 자동 테스트는 다음 커밋 전 실행한다.

## 다음 작업 시 참고

- 이 수정은 Supabase 테이블·데이터·연결 정보를 바꾸지 않는다.
- 사진 장소 확인과 단계 안내가 함께 보이는 모바일 실제 흐름을 재확인한다.
