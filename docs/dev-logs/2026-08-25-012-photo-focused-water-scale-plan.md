# 사진 기반 물때 청소 순서

## 무엇을 만들었는지

- 사진 분석 결과에 `핵심 문제` 필드를 추가했다: 물때·광물 자국, 비누막, 기름때, 먼지·부스러기, 물건 정리, 세탁.
- 사용자가 AI 제안을 수정할 수 있는 핵심 문제 선택 UI를 추가했다.
- 싱크대에서 물때·광물 자국을 선택하면 거름망 청소 대신 수전 물때 제거 단계가 표시된다.
- 수전 물때 단계는 부드러운 천, 식초와 따뜻한 물 1:1, 작은 곳 시험, 깨끗한 물 헹굼, 완전 건조와 제품 혼합 금지를 안내한다.

## 문제·막힌 지점

장소와 작업 분류만으로는 수전 물때와 거름망 찌꺼기처럼 사진 속에서 다른 청소 대상이 있어도 동일한 싱크대 기본 순서가 나왔다.

## 해결

사진의 시각적 핵심 문제를 별도 구조화 값으로 받고, 장소·분류·핵심 문제 조합에 따라 계획을 선택하도록 변경했다. 수전 관리사 공식 안내의 1:1 식초·물 방법은 수전 표면에 한정하고, 미확인 코팅은 작은 곳부터 확인하도록 제한했다.

## 다음 작업 시 참고

식초·산성 성분은 표면 코팅과 재질에 따라 제한될 수 있다. 다른 수전 브랜드·코팅의 사용설명서가 있으면 해당 제품 안내를 우선한다. 식초를 표백제·암모니아계·다른 세정제와 섞는 방법은 절대 안내하지 않는다.

## 검증

- JavaScript 문법 검사
- 서버 분석 스키마의 핵심 문제 필드 확인
- 싱크대 물때 계획의 1:1·헹굼·혼합 금지 문구 정적 검사
