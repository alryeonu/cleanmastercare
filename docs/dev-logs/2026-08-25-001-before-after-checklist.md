# 전후 사진 3단계 미션

## 무엇을 만들었는지

- 청소 전과 후 사진 입력을 한 화면에 나란히 배치하고 각 사진을 즉시 미리보기로 표시했다.
- 전후 사진 분석 응답에 `주변 정리`, `흔적 닦기`, `마무리 정리`의 세 완료 흔적을 추가했다.
- 같은 장소로 확인된 사진에서만 완료 항목을 체크리스트로 보여주고, 확인된 각 항목에 3포인트를 지급한다.
- 전후 사진 조합의 SHA-256 해시만 localStorage에 보관해 동일 조합의 중복 적립을 막았다. 원본 사진은 저장하지 않는다.
- 기본 OpenAI 모델을 `gpt-5.6-luna`로 맞췄다.

## 문제·막힌 지점

기존 프로젝트는 청소 후 사진을 미션 종료 뒤에만 받았고, 전후 분석은 변화 설명과 일괄 기록 보상만 제공했다. 같은 사진을 반복 올렸을 때 포인트 중복도 막지 못했다.

## 해결

사진 입력을 미션 첫 화면의 `BEFORE`/`AFTER` 두 칸으로 옮겼다. 분석 스키마에 사진으로 확인 가능한 세 가지 완료 흔적을 강제했고, 동일 장소가 아닐 때는 모두 false를 반환하도록 프롬프트를 제한했다. 클라이언트는 사진 데이터가 아닌 해시만 저장한다.

## 다음 작업 시 참고

AI 키가 없는 수동 모드에서는 사진 기반 체크리스트와 보상이 열리지 않는다. 실제 키가 있는 환경에서 동일 장소·다른 장소·동일 사진 반복 업로드를 각각 점검하고, 필요하면 수동 확인 흐름을 추가한다.

## 검증

- `node --check static/app.js` 통과
- `py -m pytest -q` 통과: 15개 테스트
- `py -B -c "import server; ..."`로 서버 로딩, 전후 분석 스키마와 고정 모델을 확인
- 검증용 서버를 포트 8001에서 실행하고 `GET /`가 `200`을 반환하는 것을 확인
- `py -m py_compile server.py`는 공유 폴더의 `__pycache__` 쓰기 권한 오류로 실패했다. 바이트코드 생성을 끈 로딩 검증은 통과했다.
- 자동 브라우저 화면 캡처는 이 환경의 localhost 접근 정책으로 실행하지 못했다. 실제 사용 환경에서는 전·후 사진 선택, 동일 조합 재시도, 다른 장소 사진을 함께 점검한다.
