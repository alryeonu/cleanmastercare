# 익명 글 등록 안내

## 무엇을 만들었는지

- 익명 게시글 등록에 필요한 제목·내용·삭제용 비밀번호를 화면에 명확히 안내했다.
- 빠진 입력값이 있을 때 해당 입력칸으로 이동하고 원인을 토스트로 표시하게 했다.

## 문제·막힌 지점

- 삭제용 비밀번호를 필수로 추가한 뒤, 브라우저 기본 검증만으로는 글 등록이 왜 막혔는지 알기 어려웠다.

## 해결

- 등록 전 입력값을 직접 검사해 한국어 안내와 포커스를 제공했다.

## 다음 작업 시 참고

- 운영 단계에서는 비밀번호 강도 표기와 접근성 오류 요약을 추가할 수 있다.

## 검증

- JavaScript 문법 검사와 등록 입력 안내 정적 확인을 실행한다.
