# 사진 비교 체크리스트 포인트 정렬

## 무엇을 만들었는지

- 사진 비교 체크리스트의 보상을 기존 청소 미션 한 단계와 같은 `3P` 상수로 통일했다.
- 체크리스트 안내와 각 완료 항목 표시에 같은 상수를 사용해 문구와 실제 적립액이 달라지지 않게 했다.
- 전후 사진 조합 해시가 아니라 행동 단계 코드로 당일 reward key를 만들도록 바꿔, 다른 사진 조합으로 같은 단계를 다시 확인해도 중복 적립되지 않게 했다.

## 문제·막힌 지점

- 체크리스트 표시와 적립 코드가 각각 `3`을 직접 사용해, 기존 미션 보상 기준을 바꾸면 쉽게 어긋날 수 있었다.
- 적립 key에 사진 조합 해시가 들어가 있어 같은 날 다른 전후 사진으로 같은 행동을 다시 확인하면 중복 적립될 수 있었다.

## 직접 원인과 근본 원인

- 보상 정책이 하나의 상수·행동 key로 모델링되지 않고 화면 문구와 reward 호출에 분산돼 있었다.

## 해결

- `CARE_STEP_POINTS = 3`을 청소 한 단계와 사진 비교 체크리스트가 함께 사용하도록 했다.
- reward key를 `photo-mission-${단계코드}`로 고정해 `reward()`의 날짜 단위 중복 방지와 같은 기준을 적용했다.

## 실행한 테스트와 실제 결과

- `py -m pytest -q`: 25 passed.
- `node --check static/app.js`: 성공.
- 정적 계약 테스트로 상수 사용, 화면 문구, 날짜 단위 reward key, 이전 사진 해시 기반 적립 key 제거를 확인했다.

## 남은 위험과 제한

- 기존 브라우저에 사진 해시 기반으로 저장된 과거 reward event는 자동 변경하지 않는다. 변경 후부터 같은 날 같은 행동의 새 중복 적립이 방지된다.
