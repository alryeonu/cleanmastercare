# 공식 루틴 기반 미션 방법

## 무엇을 만들었는지

- 사진으로 선택한 장소·작업 유형별 미션에 `준비 → 공간별 실행 → 마무리` 단계를 추가했다.
- 정리에는 수거 바구니와 한 구역 집중, 청소에는 도구를 한곳에 준비하고 물건을 먼저 비우는 순서, 세탁에는 라벨 우선 확인과 완전 건조를 반영했다.
- 청소 단계의 마무리에는 물기와 부스러기를 즉시 처리하는 습관을 넣었다.
- 안내 문구에 American Cleaning Institute의 집 청소 루틴 원칙을 참고했음을 표시했다.

## 문제·막힌 지점

- 기존 미션은 공간별 세부 행동은 있었지만, 일을 시작하는 준비와 끝낸 뒤의 정리 원칙이 일관되게 드러나지 않았다.
- PRD의 초기 범위는 세제 사용량·희석비율을 제외하지만, 현재 사용자 요청은 더 구체적인 청소 방법을 요구한다.

## 해결

- American Cleaning Institute의 Home Cleaning Routine에서 제시한 한 번에 한 구역 수행, 휴대 가능한 도구 모음, 먼저 정리하기, 세탁 라벨 따르기, 물기와 오염을 바로 처리하기 원칙만 일반적인 단계로 반영했다.
- 특정 제품, 재질 적합성, 새 희석비율 또는 접촉시간은 추가하지 않았다.

## 다음 작업 시 참고

- 사진 분석 결과가 물때·기름때·먼지 등 핵심 문제를 정확히 전달하는지 먼저 확인한 뒤, 해당 문제에 맞는 공간별 실행 단계만 노출한다.
- 외부 청소 자료를 반영할 때는 출처의 권장 범위를 벗어난 제품·화학 조합·사용량을 생성하지 않는다.
