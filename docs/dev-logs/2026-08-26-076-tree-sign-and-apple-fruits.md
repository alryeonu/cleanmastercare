# 기억의 나무 펫말과 사과 열매

## 무엇을 만들었는지

- 현재 주 기억의 나무가 들어 있는 격자 칸에 `8월의 넷째 주 나무` 형식의 펫말을 표시했다.
- 기본 나무에 추가 잎 네 장을 더해, 한 칸 안에서도 잎이 풍성하게 보이도록 했다.
- 청소 미션 완료 횟수에 맞춰 사과 열매가 하나씩 누적되도록 사과 모양·크기·위치를 보강했다.

## 문제·막힌 지점

- 기존 열매 수는 데이터에 반영됐지만, 격자 안에서 작고 일렬로 보여 성취 1회당 열매가 늘어나는 변화가 충분히 눈에 띄지 않았다.
- 현재 주 나무의 시기를 나무 자체에서 바로 알 수 없었다.

## 해결

- 현재 나무가 놓인 격자 칸에 주간 키 기반의 펫말을 동적으로 추가했다.
- 기존 `data-fruit-count` 규칙을 유지하며 사과의 색·잎·그림자와 가지 사이 배치를 CSS로 보강했다.
- 기존 나무 구조를 바꾸지 않고 추가 잎 요소를 초기 렌더에서 보충해 저장된 이전 화면도 호환되게 했다.
