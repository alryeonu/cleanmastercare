# 확대·축소 화면 모드

## 무엇을 만들었는지

- 우측 상단의 `가 간편 모드` 버튼을 `확대 모드`로 바꿨다.
- 확대 상태에서는 버튼이 `축소 모드`로 바뀌어 현재 동작을 알 수 있게 했다.

## 문제·막힌 지점

- 기존 명칭은 실제 기능인 큰 글씨·큰 버튼 표시를 직관적으로 설명하지 못했다.

## 해결

- 기존 확대 스타일과 저장 기능은 유지하고, 버튼 텍스트 및 접근성 라벨만 상태에 맞춰 동적으로 갱신했다.

## 다음 작업 시 참고

- 더 세밀한 크기 조절이 필요하면 확대 배율 선택 UI를 별도로 추가한다.

## 검증

- JavaScript 문법 검사와 정적 문구 확인을 실행한다.
