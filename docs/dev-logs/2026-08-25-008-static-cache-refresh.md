# 정적 파일 캐시 갱신

## 무엇을 만들었는지

- 수정된 앱 JavaScript와 보조 스타일시트의 URL 버전을 올려 브라우저가 최신 파일을 다시 받도록 했다.

## 문제·막힌 지점

서버는 정상적으로 200을 반환했지만, 이전과 같은 정적 파일 버전 문자열을 사용하면 브라우저가 기존 JavaScript를 계속 사용할 수 있다. 이 경우 새 HTML 구조와 오래된 이벤트 코드가 맞지 않을 수 있다.

## 해결

`app.js`와 `care-scope.css`의 쿼리 버전을 갱신했다. 새로고침 시 최신 단계·사진 등록 동작이 로드된다.

## 다음 작업 시 참고

정적 HTML/CSS/JavaScript를 수정할 때는 스크립트·스타일 URL의 버전을 함께 바꾸거나 캐시 정책을 명확히 설정한다.

## 검증

- 로컬 포트 8002에서 앱 HTML이 200으로 응답하는 것을 확인
- 새 JavaScript URL이 HTML에 포함됐는지 정적 검사
