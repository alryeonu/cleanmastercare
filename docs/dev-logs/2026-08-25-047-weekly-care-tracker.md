# 주간 돌봄 트래커와 집 앞 텃밭

## 무엇을 만들었는지

- 로그인별로 처음 한 번 장소 카드를 2~5곳 선택하면 7일의 작은 돌봄 계획을 자동 분산하는 주간 트래커를 만들었다.
- 오늘 카드에는 장소, 부담 없는 할 일, 청소 전 사진 입력과 기록 버튼만 표시한다.
- 사진 원본은 처리 뒤 보관하지 않고 완료 기록과 기억의 조각만 브라우저 저장소에 남긴다.
- 음성 안내와 단계별 청소 인증 흐름을 제거했다.
- `기억`과 `기록`을 하나의 화면으로 합치고 하단 메뉴를 다섯 개로 줄였다.
- 텃밭에 집을 추가해 집 앞 정원처럼 보이게 했다.
- 완료된 주간 계획도 텃밭 성장 단계에 반영했다.

## 해결

- OpenAI는 기존 안전 규칙에 따라 사진의 관찰과 비교 역할만 유지했다.
- 주간 계획은 AI 연결 여부와 무관하게 선택 장소를 균등 배치하는 결정론적 계획으로 구현했다.
- Supabase의 검수된 청소 절차 조회와 FastAPI 경로는 변경하지 않았다.

## 다음 작업 시 참고

- 주간 계획은 로그인별 브라우저 저장소에 보관하며 Supabase에는 사용자 계획·사진을 저장하지 않는다.
- 계획 생성 UI를 변경해도 사진 원본 비저장과 일일 중복 보상 방지 규칙을 유지한다.
