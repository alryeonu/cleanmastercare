# 익명 청소 이야기와 캐릭터 로고

## 무엇을 만들었는지

- 하단 내비게이션에 `이야기` 화면을 추가하고, 익명으로 청소 꿀팁·오늘의 이야기·질문을 작성하고 목록으로 볼 수 있게 했다.
- 게시글은 제목·내용만 받고 사진, 닉네임, 위치 등 개인정보 입력을 받지 않는다.
- 상단의 글자 `고` 마크를 대표 스위퍼 캐릭터가 네모 안을 채우는 로고로 교체했다.

## 문제·막힌 지점

- 현재 MVP에는 로그인과 데이터베이스가 없어 영구적인 다중 사용자 게시판을 바로 제공할 저장소가 없다.

## 해결

- 서버 메모리에 최근 100개를 유지하는 익명 게시판 API를 만들고, 서버 재시작 시 초기화된다는 사실을 작성 화면에 표시했다.
- 사진을 사용하지 않아 기존 사진 원본 미저장 원칙도 유지했다.

## 다음 작업 시 참고

- 실제 운영 커뮤니티로 확장할 때는 로그인 없는 난수 작성 토큰, 신고·차단·관리자 검토, 지속형 데이터베이스와 개인정보·보존 정책을 먼저 설계한다.

## 검증

- `node --check static/app.js` 통과.
- 기존 FastAPI 회귀 테스트는 15개 통과 표시를 확인했다.
- `GET /api/community/posts`, `POST /api/community/posts`로 익명 글 조회·등록·재조회가 되는지 확인했다.
