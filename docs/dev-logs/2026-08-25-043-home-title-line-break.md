# 홈 제목 줄바꿈 정리

## 무엇을 만들었는지

- 홈 제목을 두 개의 의미 단위로 분리했다.
  - `깨끗함을 평가하지 않고,`
  - `시작할 용기를 돕습니다.`
- 넓은 화면에서 두 문장이 각각 한 줄을 유지하도록 제목 크기와 홈 레이아웃 비율을 조정했다.
- 정적 스타일 캐시 식별자를 갱신했다.

## 문제·막힌 지점

- 큰 제목의 폭이 왼쪽 영역보다 넓어지면서 `고,`, `다.`처럼 글자 단위로 내려갔다.

## 해결

- 제목의 두 문장을 블록 요소로 분리하고, 데스크톱 폭에서는 줄 안쪽 줄바꿈을 막았다.
- 데스크톱 제목 최대 크기를 낮추고 텍스트 영역 비중을 늘려 두 줄이 안정적으로 들어가게 했다.
- 좁은 화면에서는 기존 반응형 줄바꿈을 유지해 가로 넘침을 막았다.
