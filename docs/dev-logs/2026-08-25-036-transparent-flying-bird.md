# 투명 배경 비행 새

## 무엇을 만들었는지

- 참고 새 이미지를 편집해 체크무늬·흰 배경과 뒤쪽 장식 선을 제거한 투명 PNG를 만들었다.
- 새가 돌봄 농장 하늘의 왼쪽에서 오른쪽으로 반복 비행하도록 CSS 애니메이션을 적용했다.
- 모션 감소 설정에서는 비행을 멈추고 하늘 오른쪽에 정적으로 표시한다.

## 문제·막힌 지점

- 참고 원본은 RGB 이미지라서 웹 화면의 하늘 위에 흰 체크무늬 배경이 드러났다.

## 해결

- 이미지 편집으로 배경 알파를 0으로 만들고 새만 남겼다.
- 하늘 컨테이너를 잘라내기 영역으로 설정해 화면 밖에서 시작해 오른쪽으로 지나가도록 구성했다.

## 실행한 테스트와 실제 결과

- 새 PNG 왼쪽 위 픽셀의 alpha 값: `0`.
- 실제 브라우저에서 `farmBirdFly` 애니메이션과 왼쪽 좌표 변화를 확인했다.
- `node --check static/app.js`: 성공.
- `py -B -m pytest -q -p no:cacheprovider`: 28 passed.
