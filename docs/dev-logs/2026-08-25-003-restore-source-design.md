# 원본 디자인 언어 복원

## 무엇을 만들었는지

- 전후 사진과 체크리스트 기능은 유지하면서, 화면 스타일을 공유받은 프로젝트의 기존 `styles.css` 디자인으로 되돌렸다.
- 별도로 덧입힌 사진 미션 카드·보조 스타일시트를 제거했다.

## 문제·막힌 지점

새로 추가한 카드 스타일이 기존 농장·민트 디자인 언어보다 더 강하게 보였고, 사용자가 공유한 원본 디자인을 기준으로 해달라는 의도와 맞지 않았다.

## 해결

원래 카드, 업로드 영역, 비교 그리드, 타이포그래피와 색상 규칙을 그대로 사용하도록 HTML을 복원했다. 기능에 필요한 BEFORE/AFTER 라벨과 체크리스트만 기존 구조 위에 남겼다.

## 다음 작업 시 참고

디자인 작업 전에는 새 장식 요소를 추가하기보다 공유된 정적 화면의 컴포넌트·색상·간격을 먼저 재사용한다.

## 검증

- JavaScript 기능 파일은 변경하지 않았으며 `node --check static/app.js`를 다시 실행한다.
- HTML에서 전·후 사진 입력 ID가 각각 하나씩만 유지되는지 확인한다.
