# 청소의 정석 사례형 STEP 안내

## 무엇을 만들었는지

- `청소의 정석` 공개 글과 연결된 영상 사례를 미션 STEP에 표시하는 사례 참고 카드를 추가했다.
- 물때와 기름때로 선택한 청소 미션에서는 첫 실행 STEP에 작은 구역 단위로 닦기, 깨끗한 천 면으로 바꾸기, 물기·세제 잔여물 마무리 같은 구체적인 동작을 표시한다.
- 카드에서 해당 사례의 원문과 영상 링크가 포함된 청소의 정석 글을 새 탭으로 열 수 있게 했다.

## 문제·막힌 지점

- YouTube 채널 페이지는 검색 도구에서 직접 불러오지 못했다.
- 같은 운영자의 공개 글에는 영상 링크가 있었지만, 일부 사례는 세제 혼합과 방치시간을 포함해 현재 서비스의 안전 범위를 벗어났다.

## 해결

- 운영자가 같은 `cleanstandard66` 공개 글 중 욕실 물때·주방 기름때 사례를 확인해, 안전한 작업 순서만 요약해 STEP에 반영했다.
- 특정 제품, 혼합 비율, 방치 시간, 재질 적합성 판단은 노출하지 않았다.

## 다음 작업 시 참고

- 사례 링크는 참고용이며, 사용 전 제품 라벨과 표면 관리 지침을 우선하도록 유지한다.
