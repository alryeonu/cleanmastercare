# 둥근 모서리 얼굴 로고

## 무엇을 만들었는지

- 상단 로고를 원형에서 둥근 모서리 정사각형으로 바꿨다.
- 캐릭터 원본을 크게 확대해 빗자루 없이 얼굴만 보이도록 크롭했다.

## 문제·막힌 지점

- 이전 원형 로고는 사용자가 참고한 둥근 모서리 사각형 형태와 달랐고, 원본 전체 이미지에는 빗자루가 포함되어 있다.

## 해결

- 로고 컨테이너의 오버플로우를 활용해 얼굴 중심을 확대하고, 빗자루가 프레임 밖으로 나가게 했다.
- CSS 캐시 버전을 갱신했다.

## 다음 작업 시 참고

- 로고 크기가 변하면 원본의 얼굴 중심을 기준으로 확대 비율만 조정한다.

## 검증

- JavaScript 문법 검사와 정적 CSS 로고 설정을 확인한다.
