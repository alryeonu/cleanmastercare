# 주간 기억의 나무 열매 보상

## 무엇을 만들었는지

- 기억의 나무를 주 단위 한 그루로 바꾸고, 하루 청소 미션을 완료할 때마다 그 주 나무에 열매 하나를 맺도록 변경했다.
- 미션마다 기존처럼 돌봄 포인트 3점을 누적하고, 다섯 번째 열매에는 보너스 돌봄 포인트 5점을 추가했다.
- 새 주가 시작될 때에만 지난 주 나무와 기록을 과수원에 보관하고, 새 나무를 자동으로 시작하게 했다.
- 집 그래픽을 제거하고, 현재 나무에는 다섯 열매의 실제 누적 상태를 표시했다.

## 문제·막힌 지점

- 기존 구현은 미션 다섯 번마다 현재 나무를 즉시 과수원으로 옮기고 새 나무를 시작해, 한 주 동안 한 나무를 돌본다는 흐름을 표현하지 못했다.
- 기존 회귀 테스트도 15포인트 완성 나무 전제를 검사하고 있었다.

## 해결

- 주 시작일 키와 현재 나무의 열매 수·보너스 지급 여부를 브라우저 저장 상태에 추가했다.
- 주가 바뀐 경우에만 현재 나무를 과수원 기록으로 변환하도록 분리했다.
- 열매 수에 따라 CSS에서 첫 번째부터 다섯 번째까지 하나씩 보이도록 바꾸고, 다섯 번째 열매에만 은은한 반짝임을 유지했다.
- 요구사항과 회귀 테스트를 주간 열매 규칙에 맞게 갱신했다.

## 남은 위험과 제한

- 기존 브라우저 저장 상태는 첫 접근 시 현재 주 나무로 정규화된다. 이전 기록의 실제 주차를 복원하는 별도 마이그레이션은 하지 않는다.
- 보너스 포인트는 실제 쿠폰이나 결제와 연결되지 않는 누적 돌봄 포인트다.
