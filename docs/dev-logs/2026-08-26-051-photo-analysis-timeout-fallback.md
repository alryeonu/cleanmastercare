# 사진 분석 시간 제한과 직접 선택 대체

## 무엇을 만들었는지

- 업로드 사진의 긴 변을 1280px로 축소하고 JPEG 품질 0.72로 압축해 메모리에서만 서버로 전송하도록 조정했다.
- 모든 JSON POST 요청에 `AbortController` 시간 제한을 적용했고, 사진 공간 분석은 최대 35초 뒤 중단된다.
- 분석 요청 중에는 로딩 화면을 표시하고 성공·오류·시간 초과 모두 `finally`에서 닫는다.
- AI 분석이 지연되거나 실패하면 주간 계획 안에서 공간을 직접 고를 수 있는 선택지를 표시하고 기본 안내로 계속한다.
- `cleaning_area` 분석은 OpenAI 저해상도 이미지 입력과 low reasoning을 사용하고, 서버 측 요청 제한은 25초로 낮췄다.
- 분석 오류는 API 키나 내부 세부 정보를 노출하지 않는 읽을 수 있는 JSON 오류로 반환한다.
- Vercel의 실제 Python 진입 파일 `server.py`를 `functions` 설정으로 지정하고 `maxDuration: 60`을 설정했다.

## 문제·막힌 지점

- OpenAI 사진 분석이 지연될 때 브라우저 fetch에 종료 시간이 없어 주간 계획의 안내 문구가 계속 남을 수 있었다.

## 해결

- 프런트엔드·서버·Vercel 함수의 시간 제한을 각각 설정하고, 실패 경로도 동일한 화면 렌더링과 직접 선택 경로로 마무리했다.
- 재질 직접 선택은 제품의 재질 적합성 판정 범위를 만들 수 있어 추가하지 않았고, 공간과 관찰 후보의 직접 선택만 제공한다.
