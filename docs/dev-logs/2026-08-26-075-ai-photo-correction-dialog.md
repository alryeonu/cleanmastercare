# AI 사진 인식 수정 팝업

## 무엇을 만들었는지

- NORMAL 사진 분석 뒤 선택 입력을 즉시 보여 주지 않고, AI가 인식한 공간·오염·강도·표면 후보를 키워드 문장으로 표시한 뒤 바로 Supabase 청소 방법을 불러오게 했다.
- 청소 안내 카드 모서리에 `잘못되었나요?` 버튼을 추가했다.
- 버튼을 누른 경우에만 팝업에서 청소 공간·오염 종류·오염 강도·표면 후보를 직접 수정하고, 수정값으로 안내와 제품 추천을 다시 조회할 수 있게 했다.

## 문제·막힌 지점

- 기존 흐름은 사진 분석 뒤마다 선택 입력을 요구해, 맞게 인식한 경우에도 한 단계를 더 거쳐야 했다.
- 안내 조회 기준 공간을 사용자가 수정했을 때 주간 카드와 안내가 분리되지 않도록 계획 공간 식별값을 별도로 유지해야 했다.

## 해결

- 분석 성공 시 AI 후보를 즉시 `POST /api/cleaning-guide`에 전달하도록 변경했다.
- 안내 데이터에 `planArea`를 유지해, 사용자가 팝업에서 다른 공간 후보를 고른 뒤에도 오늘의 주간 카드 안에서 수정된 안내가 이어지게 했다.
- 팝업은 사용자가 명시적으로 요청할 때만 열리며, 사진·API 키·개인정보는 저장하지 않는다.
