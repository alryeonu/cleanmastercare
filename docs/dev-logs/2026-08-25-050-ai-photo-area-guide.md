# 사진 관찰 기반 주간 청소 안내

## 무엇을 만들었는지

- 주간 계획에서 비포 사진을 고르면 먼저 `/api/analyze`의 `cleaning_area` 모드로 사진 속 공간 후보를 분석하도록 변경했다.
- AI가 관찰한 공간 후보를 `/api/cleaning-guide`의 `area_hint`로 사용해 Supabase의 청소 절차를 조회한다.
- 계획에 싱크대가 배정됐어도 욕실 사진이 관찰되면 욕실 절차를 보여 주고, 사진에서 관찰한 공간 후보라는 안내를 표시한다.
- 사진 분석 프롬프트에서 계획 장소를 정답으로 강제하던 문구를 제거했다.

## 문제·막힌 지점

- 주간 계획의 장소가 곧바로 지식 조회 입력으로 사용돼, 실제 사진과 다른 싱크대 절차가 표시될 수 있었다.

## 해결

- 사진 분석에는 중립적인 `other` 컨텍스트를 보내고, 서버도 계획 장소가 사진 판정의 정답이 아님을 명시했다.
- AI가 연결되지 않거나 분석에 실패하면 기존 계획 장소의 기본 안내로 계속할 수 있게 하되, 이를 사진 분석 결과로 표시하지 않는다.

## 테스트

- `node --check static/app.js`
- `py -B -m pytest -q -p no:cacheprovider`
- `git diff --check`

## 다음 작업 시 참고

- Supabase 청소 지식은 서버 경유로만 조회하며, 브라우저가 DB를 직접 읽거나 사진을 저장하지 않는다.
- 사진에서 관찰하지 못한 공간은 AI가 단정하지 않고 기본 안내 대체 경로로 남긴다.
