# 제품 추천 카드 공간 효율화

## 무엇을 만들었는지

- NORMAL 모드의 `AI 제품 추천`을 데스크톱에서 두 개의 작은 가로 카드로 표시하도록 정리했다.
- 실제 제품 사진, 제품명, 용도, 안전 주의와 쿠팡 검색 버튼은 모두 유지하면서 카드의 여백과 글자 크기를 줄였다.
- 모바일에서는 한 열로 바뀌지만 제품 사진과 내용이 같은 카드 안에서 밀도 있게 보이도록 했다.

## 문제·막힌 지점

- 제품 사진이 표시되는 경우에도 대체 아이콘 영역이 남아 카드 텍스트가 아래로 밀렸고, 카드가 불필요하게 세로로 길어졌다.

## 직접 원인과 근본 원인

- 대체 아이콘의 CSS `display:grid`가 HTML의 `hidden` 속성보다 우선 적용되어 숨겨진 요소도 그리드 칸을 차지했다.
- 이후 카드 확대용 CSS가 이전의 두 열 레이아웃을 한 열의 큰 카드로 덮어써서 화면 여백이 더 커졌다.

## 해결

- `.product-image-fallback[hidden]`에 `display:none!important`를 적용해 실제 제품 사진이 성공적으로 로드될 때 대체 아이콘이 레이아웃에서 완전히 제거되도록 했다.
- 제품 카드 그리드를 두 열로 복원하고, 이미지 92px·간결한 카드 여백·작은 정보 글꼴로 조정했다.
- 정적 CSS·JavaScript의 캐시 버전을 `weekly-guide18`로 올려 배포 후 이전 스타일이 남지 않게 했다.
