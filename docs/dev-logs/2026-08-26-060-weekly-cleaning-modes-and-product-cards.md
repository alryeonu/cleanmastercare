# 주간 청소 모드와 제품 참고 카드

## 무엇을 만들었는지

- 주간 계획의 첫 설정과 진행 화면에 `EASY`, `NORMAL` 모드 선택을 추가했다.
- EASY는 기존 사진 분석과 Supabase 청소 안내 호출을 유지하면서 안내를 최대 두 행동으로 제한하고 제품 참고 영역을 숨긴다.
- NORMAL은 기존 상세 안내를 유지하고, 사진에서 관찰한 공간·오염 후보와 사용자가 직접 고른 표면 재질을 바탕으로 제품 참고 카드 두 개를 표시한다.
- 제품 사진·유형·이름·목적·주의·쿠팡 검색 질의는 `static/product-links.js`에 분리했다. 이후 제휴 링크나 API를 도입할 경우 이 데이터만 바꾸면 된다.

## 문제·막힌 지점

- 이전 PRD와 회귀 테스트는 외부 상품 추천을 제외 범위로 전제하고 있었다.
- 주간 사진 분석은 공간뿐 아니라 `cleaning_focus`를 반환하지만, 기존 화면은 그 값을 안내 검색과 표시 상태에 전달하지 않았다.
- 실제 브라우저 자동화 연결이 새 로컬 탭을 인식하지 못해 이번 세션에서 화면 캡처 기반 반응형 점검을 완료하지 못했다.

## 직접 원인과 근본 원인

- 제품 추천은 과거 MVP의 명시적 제외 기능이었고, 테스트도 쿠팡 문자열 부재를 검사했다.
- 주간 경로가 사진 장소 일치 확인을 우선하며 세부 오염 후보를 버리고 있었다.

## 해결

- 최신 사용자 요청을 범위 변경으로 반영해 PRD의 제외 범위·기능 요구사항·수용 기준을 갱신했다.
- 사진 분석 성공 시 `visible_categories`, `cleaning_focus`를 주간 청소 안내와 정적 카탈로그 선택에 전달했다.
- 재질은 AI가 추정하지 않으며 사용자가 직접 선택하도록 했다.
- 곰팡이 관련 카드에 염소계 제품과 산성세제·식초·구연산·암모니아 제품 혼합 금지 문구를 넣고, 천연석·원목·패브릭 주의와 라벨·표면 제조사 안내 우선 문구를 카드에 포함했다.
- 상품 링크는 쿠팡 파트너스 API 없이 제품명 검색 결과로만 연결한다.

## 남은 위험과 제한

- 제품 사진은 정적 외부 이미지 URL이다. 원본 사이트에서 이미지를 교체하거나 차단하면 카드의 대체 아이콘이 표시된다.
- 제품 추천은 구매·성능 판정이 아니라 참고용이다. 제품 라벨과 표면 제조사 안내가 우선한다.
