# 전후 사진 근거 기반 재검토

## 무엇을 만들었는지

- 전후 사진 비교가 고정 기준점 두 개 이상으로 같은 장소인지 먼저 확인하도록 프롬프트를 강화했다.
- 정리·청소·세탁 체크가 true일 때 사진에서 확인한 근거 1~2개를 함께 반환해 체크리스트에 표시한다.
- 사진 분석의 추론 수준을 높였다.

## 문제·막힌 지점

조명·촬영 거리 차이만으로도 변화처럼 보일 수 있고, 기존 체크리스트는 왜 특정 단계가 완료됐다고 판단했는지 사용자에게 보여주지 못했다.

## 해결

같은 장소 판정의 기준점을 구체화하고, 근거가 부족하면 모든 체크를 false로 반환하도록 했다. 완료 항목은 사진에서 확인된 짧은 근거를 UI에 표시한다.

## 다음 작업 시 참고

Google 자동 검색을 서버에서 수행하려면 `GOOGLE_CUSTOM_SEARCH_API_KEY`와 `GOOGLE_CUSTOM_SEARCH_CX`가 필요하다. 일반 Google 결과 페이지 수집으로 대체하지 않는다.

## 검증

- JavaScript 문법 검사
- 전후 분석 스키마에 세 작업 분류의 근거 배열이 있는지 확인
- 기존 Python 회귀 테스트
