# 오늘의 자리 브랜딩, 텃밭 장식 위치와 공개 사진 첨부

## 무엇을 만들었는지

- 화면과 서버 상태의 서비스명을 `오늘의 자리`로 바꿨다.
- 밭에 가려지던 꽃·허수아비 장식을 위쪽 레이어로 올렸다.
- 사용자 명시 승인 후 익명 게시글에 사진 한 장을 첨부하고 게시글 팝업에서 볼 수 있게 했다.

## 문제·막힌 지점

- 텃밭 장식이 밭 뒤에 렌더링돼 일부가 가려졌다.
- 사진 공개 게시글은 개인정보와 위치 정보가 노출될 수 있어 공개 범위 확인이 필요했다.

## 해결

- 장식 레이어의 z-index와 위치를 조정했다.
- JPG, PNG, WEBP를 브라우저에서 800px JPEG로 축소·압축하고 서버는 JPEG data URL·800KB 이하만 검증한다.
- 첨부 사진은 커뮤니티의 임시 메모리에만 남으며, 작성자 삭제나 서버 재시작 시 게시글과 함께 사라진다. Supabase에는 저장하지 않는다.

## 테스트

- `node --check static/app.js` — 성공.
- `py -B -c "compile(open('server.py', encoding='utf-8').read(), 'server.py', 'exec')"` — 성공.
- `py -B -m pytest -q -p no:cacheprovider` — 성공.
- `git diff --check` — 성공.

## 다음 작업 시 참고

- 공개 사진은 게시글을 보는 모든 사용자에게 보인다. 얼굴·주소·연락처가 드러나는 사진은 올리지 않도록 화면 안내를 유지한다.
