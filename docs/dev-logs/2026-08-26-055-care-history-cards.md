# 돌봄 기록 카드 보강

## 무엇을 만들었는지

- 돌봄 기록 카드를 날짜, 청소 항목, 모드(일반 모드·주간 돌봄), 격려 문구로 구성했다.
- 주간 돌봄 완료 기록에는 새싹 심기 여부에 맞는 격려 문구를 함께 남긴다.

## 문제·막힌 지점

- 기존 기록 목록은 공간명과 간단한 상태만 표시해 언제 무엇을 어떤 흐름으로 했는지 파악하기 어려웠다.
- 사용자 요청에는 애프터 사진을 `localStorage`에 보관하는 항목이 포함됐지만, 앱의 사진 원본 미저장 개인정보 규칙과 충돌한다.

## 해결

- 사진 원본이나 base64를 기록 객체에 넣지 않고, 사진 입력 여부만 유지한 채 기록 메타데이터와 격려 문구를 저장했다.
- 사진은 업로드·비교 중 현재 화면에서만 미리 보기로 유지되며 새로고침 후에는 보관하지 않는다.
