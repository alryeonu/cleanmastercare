# 커뮤니티 게시판형 목록

## 무엇을 만들었는지

- 커뮤니티의 주제 선택 입력과 게시글 주제 배지를 제거했다.
- 게시글 목록을 카드 배열에서 `번호 · 제목 · 작성자 · 등록일`이 보이는 게시판 행 형태로 변경했다.
- 게시글 목록을 글쓰기 영역보다 위에 배치하고 `글쓰기` 버튼으로 작성 영역에 바로 이동할 수 있게 했다.
- 게시글 행을 누르면 제목·내용·기존 댓글·익명 댓글 등록 폼이 열리는 기존 팝업 흐름을 유지했다.
- 서버 게시글 생성 계약에서도 주제 입력을 요구하지 않도록 정리했다.

## 문제·막힌 지점

- 첫 Production 배포에서 게시판 스타일이 기존 카드 스타일보다 먼저 선언되어, 새 행이 다시 두 개의 카드처럼 표시됐다.

## 해결

- 게시판 스타일을 기존 커뮤니티 카드 스타일 뒤로 이동해 목록 행 규칙이 최종 적용되게 했다.
- 정적 CSS 캐시 식별자를 갱신한 뒤 Production에 다시 배포했다.
- 모바일에서는 작성자 열을 숨기고 `번호 · 제목 · 등록일` 세 열만 남겨 가로 넘침을 방지했다.

## 다음 작업 시 참고

- 커뮤니티 게시글에는 주제 분류를 다시 노출하지 않는다.
- 게시글 목록에는 댓글 수와 댓글 입력칸을 표시하지 않고, 댓글 기능은 게시글 팝업 안에서만 제공한다.
