# 사진 미션 화면 디자인

## 무엇을 만들었는지

- 전후 사진 입력을 독립적인 사진 미션 카드로 디자인했다.
- 대표 캐릭터, BEFORE→AFTER 연결 화살표, 단계별 보상 칩을 추가했다.
- 청소 완료 뒤에는 사진 리포트 제목과 전·후 비교 카드를 보여주도록 구성했다.
- 모바일에서는 사진 카드가 세로로 쌓이고, 보상 칩과 비교 카드가 좁은 화면에 맞게 재배치된다.

## 문제·막힌 지점

기존 기능은 전후 사진 입력이 있었지만, 두 사진의 관계와 사진 비교로 확인하는 3개 미션의 보상 구조가 시각적으로 충분히 드러나지 않았다.

## 해결

전후 입력 영역 위에 사진 미션 안내와 캐릭터를 배치하고, 두 사진 사이에 방향 표시를 넣었다. 사진 선택 전에도 비교 카드가 어떤 역할인지 알 수 있도록 빈 상태 라벨을 추가했다.

## 다음 작업 시 참고

실제 모바일 브라우저에서 사진을 각각 넣은 뒤, 이미지가 빈 상태 라벨을 가리고 정사각 비율에 가깝게 보이는지 확인한다. 환경 정책상 자동 localhost 화면 캡처는 실행하지 못했다.

## 검증

- HTML에 전후 입력 ID가 각각 하나씩만 존재하는지 확인
- `node --check static/app.js` 통과
- 정적 스타일 파일을 별도 로드해 기존 대형 스타일시트와 충돌을 줄임
