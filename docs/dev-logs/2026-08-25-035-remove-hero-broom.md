# 홈 빗자루 장식 제거

## 무엇을 만들었는지

- 참고 자산 반영 직후 사용자 피드백에 따라 홈 마스코트의 빗자루 장식과 관련 CSS를 제거했다.
- 방금 추가했던 `static/clean-master-broom.png` 파일도 삭제했다.

## 문제·막힌 지점

- 빗자루가 기존 마스코트의 시각 언어와 어울리지 않아 의도하지 않은 장식으로 보였다.

## 해결

- 홈 화면을 기존 마스코트 중심 구성으로 되돌렸다.
- 농장 하늘의 새 일러스트는 별도 피드백이 없으므로 유지했다.

## 실행한 테스트와 실제 결과

- `node --check static/app.js`: 성공.
- `py -B -m pytest -q -p no:cacheprovider`: 28 passed.
- 실제 브라우저에서 `.hero-broom` 요소가 없고 가로 넘침이 없음을 확인했다.

## 다음 작업과 다음 세션의 첫 행동

- 참고 디자인을 반영할 때는 한 요소씩 사용자 화면에서 확인한 뒤 확장한다.
