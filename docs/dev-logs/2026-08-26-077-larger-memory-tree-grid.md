# 크게 보이는 기억의 나무 격자

## 무엇을 만들었는지

- 기억의 나무 격자를 12칸에서 6칸으로 줄여 나무 한 그루가 차지하는 칸을 넓혔다.
- 데스크톱은 3×2, 모바일은 2×3 격자로 배치했다.
- 현재 나무의 스케일과 사과 열매 크기·대비를 높여, 완료한 미션의 열매가 더 눈에 띄게 했다.

## 문제·막힌 지점

- 12칸 격자는 현재 나무를 지나치게 작게 축소해 사과가 보이지 않는 것처럼 느껴졌다.
- 이전 CSS의 반응형 축소 규칙이 뒤에서 다시 적용돼 나무가 특히 작게 보였다.

## 해결

- 격자 수와 저장 위치 유효 범위를 6칸으로 변경했다. 이전의 12칸 위치 저장값은 기존 정규화 로직으로 빈 유효 칸에 다시 배치된다.
- 최종 CSS 규칙에서 화면별 현재 나무 크기를 재정의하고, 사과에 더 큰 형태와 은은한 빛 효과를 적용했다.
