# 욕실 사진 확인 게이트

## 무엇을 만들었는지

- 주간 돌봄의 비포 사진은 청소 절차를 찾기 전에 AI가 욕실 사진인지 먼저 판단한다.
- AI가 욕실로 확인하면 `bathroom` 컨텍스트로 Supabase의 검수 청소 절차를 조회한다.
- 욕실이 아니거나 사진만으로 확인하기 어려우면 절차를 표시하지 않고 “욕실 사진을 다시 등록해주세요” 안내와 사진 교체 버튼을 보여 준다.

## 문제·막힌 지점

- 이전 흐름은 사진의 다양한 공간을 추정한 뒤 계획 장소 또는 추정 장소의 안내를 열어, 욕실이 아닌 사진에도 부적절한 청소 절차가 이어질 수 있었다.

## 해결

- `bathroom_check` 전용 JSON Schema와 프롬프트를 추가해 판정 범위를 Yes/No로 좁혔다.
- 욕실 단서가 충분하지 않은 경우 false로 처리하며, Supabase 지식 조회는 통과한 욕실 사진에서만 실행한다.
- 사진은 요청 메모리에서만 처리하고 저장하지 않는다.

## 다음 작업 시 참고

- 욕실 확인 실패는 사용자 평가가 아니라 사진 구도·단서 부족일 수 있으므로 다시 등록 안내만 제공한다.
- 욕실 청소 절차는 계속 FastAPI를 통해 Supabase에서 읽고, 브라우저가 DB에 직접 접근하지 않는다.
